# Project rules

## Authoritative requirements

Treat [`requirements.md`](requirements.md) as the authoritative Software Requirements Specification for this project.

While planning, designing, implementing, reviewing, testing, or changing this project, follow its requirements strictly. Do not intentionally introduce behaviour that conflicts with it. If a requested change conflicts with, is ambiguous under, or requires an exception to the SRS, clearly identify the conflict and obtain explicit direction before proceeding.
